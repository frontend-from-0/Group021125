## Flow used on 8 Jun (live demo, ~90 min)

1. **Concepts (20–25 min)**: walk through `notes.md`: rules (user / project `.cursor/rules/*.mdc` / team), `AGENTS.md`/`CLAUDE.md`, skills (`.cursor/skills/<name>/SKILL.md`), sub-agents (`.cursor/agents/*.md`), MCP (`.cursor/mcp.json`), hooks/modes, plugins. Summary: *rules = constitution, skills = SOPs, sub-agents = specialists, MCP = tools*.
2. **Design → PRD (20 min)**: open the Figma community file *Fintrack – budgeting app* (link in `docs/prd.md` header) and have the agent write a PRD: problem, personas, platform strategy (responsive web, no native apps), screen inventory, epics A–G, user stories with acceptance criteria, data model, out-of-scope. Review it critically with students (what did the AI invent? what is missing?).
3. **Plan mode (15 min)**: ask Cursor (Plan mode) for an MVP scaffold plan based on the PRD and on the course conventions of an existing project. In Group130625 this was `Lesson46/ecom-130625`. **For Group021125 point it at `Lesson47/ecom`** (Next 16, React 19, Tailwind 4, shadcn, Prisma, Jest, Playwright). Discuss the decisions in the plan: SQLite + Prisma, no Auth0 for MVP (single seeded demo user "Parzival"), dev port 4010, testing tools.
4. **Agent build (20–25 min)**: let the agent execute the plan todos (bootstrap Next app, deps, shadcn + design tokens, Prisma schema + seed, route stubs + AppShell with bottom nav/sidebar, lib utils, Jest/Playwright, README/env.example.md/AGENTS.md). Show reviewing diffs, running `npm run db:push && npm run db:seed && npm run dev`, `npm test`.
5. **Wrap-up (5–10 min)**: AI-generated code still needs review, tests and quality gates. Add a project rule / AGENTS.md so the agent follows conventions. Never paste secrets into prompts or commit `.env`.
